LanNative map travel test list (Absolver 1.31 b1.25_575)
=========================================================

These are root cooked maps found in the installed game's package list. They are safe names to try
with the native console while playing offline/LAN only. They are not proof that every map has its
intended game mode, spawns, or multiplayer rules when opened directly.

Host only: open one command below, then have clients use F7 to rejoin. Do not use the sub-level,
lighting, collision, sound, or PVE room paths: those are streamed parts, not standalone worlds.

----------

1v1 roots. The M3.3 logs showed that a plain <map>?listen already loads the real 1v1 game mode (1V1_GameMode_C), so ?game= is optional.
   (The game's own form is <map>?game=<class path>?listen: 1v1 = /Game/Blueprints/GameModes/1V1/1V1_GameMode.1V1_GameMode_C,
   3v3 = /Game/Blueprints/GameModes/Domination/BP_Domination_GM.BP_Domination_GM_C.)
   The game then sent offline players straight back to the main map. M3.5's PvP guard (LanNative\pvpfix.txt, on by default) stops that.
   The joiner puts the word  none  on line 2 of ip.txt and presses F7 (no co-op CheckPoint/zone for a PvP world).
