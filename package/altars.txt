LanNative altar travel list (Absolver 1.31 b1.25_575) - UNTESTED
===============================================================
What this is: the 42 respawn altars ("checkpoints") placed in the main world (MainMap_Main), with the zone number stored on each one, read from the
game's own MainMap_Main.umap. The game's AThePlainesGameMode::InitNewPlayer reads the URL options CheckPoint=<altar path> and zone=<n>
for every player who logs in and spawns that player at that altar (decompile; not yet run in game).

IMPORTANT - the zone must match the altar. If zone=<n> differs from the altar's own zone the game REPLACES the altar with that zone's
main altar. Use the zone printed next to each altar. Altars marked * have no zone stored in the map; the game treats that as 0 (the
altar your own save used, BP_RespawnAltar_03_E3Demo3, was logged with zone 0, which supports this, but the other starred ones are inferred).
Positions are the altar's AutoSave component location in map units (cm), approximate, only to tell altars apart.

Host (moves YOU): open the console (Tilde) and paste one "Open ..." line. This reloads the world with you as the host, then your
joiner presses F7 as usual.
Joiner (moves THEM): put the "ip.txt line 2" text on line 2 of LanNative\ip.txt (line 1 stays the host IP), then press F7. A nonempty
line 2 overrides the options read from the save.
The save editor lists one more spawn point, BP_RespawnAltarLight2_509, but it belongs to the tutorial map (/Game/Maps/Tutorial/Tutorial_LDIngredients), a different world, so it is not in this list.
After a test, tell me whether you arrived at the altar and what lannative.log shows for "travel request:" and "world:".
